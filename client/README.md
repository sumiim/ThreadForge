# Client — ThreadForge Web Console

ThreadForge 的 React Web 工作台。Agent 协作约定见 [AGENTS.md](AGENTS.md)。

## V1 范围

- Session 列表与新建会话。
- Agent 任务输入和最终回答展示。
- SSE 任务状态与工具事件。
- 危险工具的批准和拒绝。
- Agent 停止按钮。
- Workspace、模型和开发模式提示。

## 技术栈

- pnpm
- Vite
- React 19
- TypeScript
- Ant Design v6
- TailwindCSS v4

该模块尚未实现。V1 不包含完整 Plan 树、Agent 树、Skills 管理或桌面端打包。
